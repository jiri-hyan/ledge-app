# Codemapa: limity Claude 5h / týden

Karta Claude (a volitelně proužek) ukazuje spotřebu 5h a týdenního okna Claude s odpočtem resetu;
v čase resetu okna, které dosáhlo 100 %, vyjede krátký peek. Zdroj = stavový řádek Claude Code přes
průchozí wrapper Ledge, záložně `~/.claude/usage-log/latest.json`; volitelně (výchozí vypnuto) soubor aplikace
Claude `plan-usage-history.json` (`claude.limitsDesktop`) a dotaz na Anthropic `/api/oauth/usage` (`claude.limitsFetch`). Návod: [agents/sessions.md](../agents/sessions.md) → „Limity Claude 5h / týden“.
Detail (tok dat, invarianty a pasti, testy): [limits-detail.md](limits-detail.md).
