- **Hooky Clauda s klíčem / Claude hooks now carry a key:** most pro Clauda přijímá schvalování jen s tajným klíčem, který si Ledge při startu sám doplní do `~/.claude/settings.json` (cizí hooky nechá být). **Session spuštěné před aktualizací schvalují v terminálu, dokud se nerestartují; jejich aktivita běží dál.** Klíč je v `settings.json` doslovně: když si `~/.claude` synchronizuješ mezi stroji, budou si ho stroje navzájem přepisovat. / The Claude bridge accepts approvals only with a secret key, which Ledge adds to `~/.claude/settings.json` at startup, leaving other hooks alone. **Sessions started before the update approve in the terminal until restarted; their activity keeps showing.** The key is stored literally in `settings.json`, so machines syncing `~/.claude` will overwrite each other's key.
- **Odolnější most / A sturdier bridge:** jiný program na tomto počítači už most nezastaví pomalým požadavkem ani neshodí obří hlavičkou. Událost bez klíče nezruší čekající schvalovací kartu. Zkratky Schválit a Zamítnout ve fullscreen hře nic nerozhodnou. / Another program on this PC can no longer stall the bridge with a slow request or crash it with a huge header. An event without the key can't dismiss a pending approval card. The Approve and Deny hotkeys decide nothing in a fullscreen game.
- **Rozbitý config už nezahodí nastavení / A broken config no longer costs you your settings:** jedna špatná hodnota vrátí na výchozí jen svou sekci, ne celý soubor. Před přepsáním vznikne kopie `config.json.broken-<čas>` a banner nabídne Obnovit, Ukázat složku a Zavřít. Při chybě v ruční úpravě běží poslední platná verze a banner to řekne. / One bad value resets only its section, not the whole file. A `config.json.broken-<time>` copy is made before overwriting, and a banner offers Restore, Show folder and Close. A faulty manual edit keeps the last valid version running, and the banner says so.
- **Poznámky v jiném kódování / Notes in other encodings:** poznámku, která není v UTF-8, už nejde uložit, soubor zůstane beze změny. Dřív první uložení nahradilo diakritiku za `�`. / A note that isn't UTF-8 can no longer be saved and the file stays untouched. Previously the first save replaced accented characters with `�`.
- **Poznámky a lístky bez tiché ztráty / Notes and pins without silent loss:** dvě nové poznámky ve stejné sekundě se už nepřepíšou. Poškozený `desk.json` nebo `note-pins.json` se před přepsáním zkopíruje a událost se zapíše do `ledge.log`. / Two new notes created in the same second no longer overwrite each other. A corrupted `desk.json` or `note-pins.json` is copied before being overwritten and logged to `ledge.log`.
- **Účty a vracení změn / Accounts and undo:** odhlášený účet se při obnově tokenu už nevrátí a přihlášení se do Správce pověření ukládá až po úspěchu. MCP `undo_last` po odmítnutém vrácení nepřeskočí na starší změnu. / A signed-out account no longer comes back when a token refreshes, and sign-in saves to Credential Manager only after it succeeds. MCP `undo_last` no longer skips to an older change after a refused undo.
- **Chyby v okně už nezůstanou potichu / Window errors no longer stay silent:** chyba v kartě ukáže větu a Zkusit znovu, zbytek šuplíku jede dál a chyba jde do `ledge.log`. Lístek při chybě obsahu zachová lištu i rozepsaný text. Studio má všechna oprávnění, která jeho panely potřebují: Nainstalovat aktualizaci, Prohledat znovu, Obnovit teď a další tlačítka fungují. / An error in a card shows a message and Try again, the rest of the drawer keeps working, and the error goes to `ledge.log`. A pin keeps its bar and your unsaved text when its content fails. Studio now has the permissions its panels need, so Install update, Scan again, Refresh now and other buttons work.
- **Dev servery / Dev servers:** Ready pozná i server, který vypíše jen `listening on http://localhost:3000`, s prodlevou asi 3 s. / Ready now also detects a server that only prints `listening on http://localhost:3000`, after about 3 s.
- **Méně práce na pozadí / Less background work:** periodický `git status` se ve hře pozastaví a schvalovací karta už nezmizí, když doběhne jiný nástroj. / The periodic `git status` pauses during games, and an approval card no longer disappears when a different tool finishes.
