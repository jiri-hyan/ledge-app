- **Opraveno: uříznutý šuplík / Fixed: cut-off drawer.** Po změně výšky v 0.11.0 mohl Ledge zamrznout na nízké výšce (jen hlavička a řádek projektů) a nepomohl ani restart. Výška se už nikdy neodvozuje od velikosti okna. / After a height change in 0.11.0 the drawer could get stuck at a low height (just the header and the project row), even after a restart. The height is no longer derived from the window size.
- **Ledge Studio se otevírá místo šuplíku / Ledge Studio opens instead of the drawer:** šuplík se při otevření Studia zavře, takže Studio už nezůstane schované pod ním, a okno Studia leží pod proužkem. / the drawer closes when Studio opens, so Studio no longer ends up hidden behind it, and the Studio window sits below the strip.
- **Vlastní okno není hra / Own window is not a game:** Studio roztažené přes celý monitor už Ledge nebere jako hru na celé obrazovce. / Studio stretched over the whole monitor is no longer treated as a full-screen game.
